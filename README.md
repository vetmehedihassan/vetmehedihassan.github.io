# Dr. Md. Mehedi Hassan — Personal Portfolio

A responsive personal veterinarian portfolio inspired by the supplied portfolio screenshot and the supplied medical portfolio reference.

## Important branding choice
Happy Tails Pet Care is presented only as the employer in the Work Experience section. Its logo is **not** used as the website's personal branding.

## Main portrait
The formal suit portrait is used as the main portfolio/hero portrait because it best fits the professional personal-portfolio presentation.

## Content source
Portfolio content is based on the latest supplied CV. The Education section intentionally omits GPA/CGPA results for a cleaner professional portfolio presentation.

## GitHub Pages
Upload the contents of this folder to a GitHub repository, then enable **Settings → Pages → Deploy from a branch → main → / (root)**.
